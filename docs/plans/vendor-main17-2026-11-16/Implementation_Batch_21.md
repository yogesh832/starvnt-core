# Academy catalogue metadata and readiness suggestions — 17 November 2026

Partial V21.02 continuation (16.7.1 / 16.16.3). Existing lesson drafts now support a bounded catalogue description, optional recorded difficulty, featured status and explicit readiness topic tags. Web and native staff use the existing editor and independent publication process. Vendor catalogues support Featured and readiness suggestion collections alongside search/category/progress filters. Search includes the new description/difficulty; suggestions expose the matched topic names, not invented scores or promised eligibility changes.

Suggestions reuse the current Vendor activation evaluator's ten canonical metrics and calculation version/time. Only known incomplete metrics explicitly tagged by the author are considered. Current-version completion suppresses a suggestion; old-version completion does not complete revised content. Evaluation failures return an explicit unavailable status while published lessons remain browsable, including when the suggestion collection was selected. No language-model call, reward, matching boost, verification mutation, weekly challenge or external delivery is introduced.

Metadata participates in new content snapshots using hash schema version 2. Existing unversioned/schema-1 archives retain their original hashes; their unknown metadata is not reconstructed. Metadata cannot be silently added to a schema-1 archived current version. Publication validates archived content and records the corresponding schema's hash. Older clients that omit metadata preserve it on edit. Pre-metadata creation receipt hashes still recover the original unchanged draft, while adding featured metadata to the same old command is rejected.
