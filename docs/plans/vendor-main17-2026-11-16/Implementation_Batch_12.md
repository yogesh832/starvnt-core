# Aura diagnostic privacy — 17 November 2026

Partial V17.02 and V45 operational hardening. Existing Vendor Aura logging printed raw user text, replies, business names, session identifiers, saved profile values, proposed action descriptions and provider exception messages. Replaced these with an allowlisted structured diagnostic: fixed event, known action kind, fallback boolean, saved-field count and finite timing values. Unknown fields, action kinds and event strings cannot enter output. Context, Google and Gemini failure logs use fixed events rather than exception contents. Deferred quote notification/thread errors likewise omit provider text. A failed execution no longer emits a successful confirmed-action diagnostic.

This does not delete or change the separately authorized conversation history or audit records, introduce Customer logging behavior, or claim that all backend logs and historic logs are remediated. Historic retention, broader backend logging review and full privacy acceptance remain open. No identifiers or transcript fragments are added for correlation; status/timing remain available without those values.

Verification: 40 affected tests passed across vendor-aura-diagnostics.test.js, vendor-aura-capability.test.js, booking-workflow.test.js and vendor-main17-integrity.test.js. A signed-in synthetic HTTP test injects sensitive fixture text into both a vendor profile and a provider failure and confirms diagnostics omit it while still recording fallback/turn status. Unit tests reject unknown fields and prove provider objects are never serialized. Evidence: tmp/vendor-main17-implementation/aura-private-diagnostics-tests.log. The preceding full backend run passed 302 tests before this diagnostic-only change; it is not represented as a 305-test full run.

Migration: no schema/data migration. Log consumers relying on the old multiline transcript must adopt fixed events; losing raw conversation logging is intentional. Rollback must retain content omission and must not reintroduce transcript/provider exception dumps. No production logging configuration or deployment changed.
