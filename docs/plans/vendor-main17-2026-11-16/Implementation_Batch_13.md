# Academy content and resource history — 17 November 2026

Partial V23.03/V22.03 implementation using the existing Academy lesson, publication, progress and feedback models. New drafts capture exact normalized title/category/objective/text/resource/video/caption/duration content with version, SHA-256, actor and capture time. Edits append the next snapshot in the same revision-checked database update as the current content and history. Retrying the same edit recovers it without appending twice; supplied archive fields never overwrite server history. Existing snapshots are checked before read/edit to detect altered content or an unversioned change to the current content.

Older lessons retain their actual current content on the next edit with explicit RECOVERED_CURRENT_ON_EDIT provenance. Unknown earlier versions are not invented. Snapshot capture time does not claim an earlier publication time. Publication decision history separately binds the content version/hash to rights and the independent publisher.

The existing Admin Academy editor has a permission-gated, read-only saved-version view. Full archives are excluded from ordinary catalogue/current lesson reads and are loaded only through the authorized admin versions route. Old video references do not grant playback. Current publication/rights checks continue to govern Vendor lesson/resource/playback access. Withdrawal prevents new playback grants; previously granted short-lived provider URLs can persist until expiry, and downloaded content cannot be recalled. This does not migrate arbitrary legacy resource URLs into private media storage or finish the featured-resource catalogue.

Explicit labels are associated with the editor's category, objective, lesson text, resources and captions, so saved field contents do not contaminate exact label lookup. Broader accessibility/native playback acceptance remains open.
