# Proposal fonts

Noto Sans Regular/Bold, Noto Sans Devanagari Regular and Noto Sans Bengali Regular
are bundled for portable PDF generation, including Hindi/Bengali event names.
Source: `https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf`.
License: SIL Open Font License 1.1, included in `OFL.txt`.
The renderer uses Latin, Devanagari and Bengali runs; other scripts need explicit
font coverage and visual acceptance before being advertised as supported.
